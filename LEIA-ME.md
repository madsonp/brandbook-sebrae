# Brandbook Sebrae 2026

Material de consulta em português para Claude, GPT e outras LLMs, com regras, dados de cores, referências visuais e PDF original.

## Fontes de consulta

O guia operacional reúne o conteúdo do brandbook e orientações internas provisórias, pendentes de confirmação do Sebrae/NA. Consulte `dados/criterios-de-aplicacao.json` para identificar a origem das regras que mudam a decisão. Para conferir o PDF, use as páginas em `fonte-pdf/`, com suas imagens. Consulte `dados/recursos-de-producao.json` antes de produzir uma peça final.

## Como consultar

1. Abra o [índice](indice.md) e escolha o assunto.
2. Leia o capítulo correspondente ou a [versão consolidada](brandbook-consolidado.md).
3. Para decisões visuais, consulte também a imagem da página ou o PDF do capítulo.

Para usar com anexos, comece por `GUIA-PARA-LLMS.md` e `brandbook-consolidado.md`. O consolidado inclui os critérios de aplicação e a disponibilidade dos recursos de produção; não depende de abrir os JSON para identificar essas condições. Acrescente apenas os PDFs ou PNGs relevantes. Utilize o consolidado ou os capítulos, evitando carregar os dois modos ao mesmo tempo.

## Estrutura

- `fonte-pdf/`: texto extraído das 245 páginas, para conferência sob demanda.
- `regras/`: capítulos e tabelas de consulta.
- `dados/`: paleta, matrizes, gradientes, mapa de páginas e manifesto.
- `referencias-visuais/`: imagens das 245 páginas.
- `pdfs-por-capitulo/`: PDFs organizados por assunto.
- `original.pdf`: documento original completo.
- [Links de mídia](links-do-original.md): referências extraídas do PDF.

Mantenha a estrutura das pastas para preservar os links. Um caminho no Markdown não carrega a imagem automaticamente na ferramenta; anexe-a quando necessário.

Esta é uma adaptação para consulta, não uma publicação oficial do Sebrae.
